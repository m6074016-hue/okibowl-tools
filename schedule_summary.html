PURPOSE

このシートの目的

月次の振り返りだけでは「来月頑張ろう症候群」に陥る。日次・週次・四半期・半期の小刻みな振り返りで成果に直結する正社員を育てるための共通フレームを定める。

PURPOSE 1
成果責任の見える化
担当領域の数字（売上・原価・接客指標）に半期で責任を持つ。何時間働いたかではなく、何を残したかを評価する。
PURPOSE 2
役割の独立運営
店長の判断を待たずに、各正社員が自領域を主体的に改善できる組織にする。判断権限と意思決定範囲を明文化。
PURPOSE 3
キャリア発展の保証
PDP（個人成長計画）と昇格基準を明示し、努力が処遇・昇格に直結する仕組みにする。離職を防ぎチームを強くする。
02 / 05
GOAL

到達したい3つのゴール

半期（6ヶ月）で以下が達成できている状態を目指す。これが正社員に求めるクオリティ。

ゴール定義
① 数字責任各ポジションの担当KPIを半期目標 80%以上達成。未達でも原因分析と次期改善策を自ら提示できる。
② 領域オーナーシップ担当領域のSOP整備・改善提案を月1件以上アウトプット。店長の指示待ちにならない。
③ 後継人材育成自分の下に1名以上「育てる対象」を持ち、半年で独立稼働可能なレベルまで引き上げる。
正社員の最終ゴール 「自分が休んでも領域が回る状態」を半期で作る。
これができていればS〜A評価／できていなければ役割再定義の対象。
03 / 05
RULE

守るべき5つのルール

  • 日次入力ルール：毎日21:30〜22:00の間に「今日の振り返り＋明日のアクション」をapp.htmlに必ず1行ずつ記入する
  • 時間配分ルール：現場稼働は週時間の65%以下に抑える。残り35%は戦略タスク・育成・自己研鑽に使う
  • 1on1ルール：店長と毎月30分の1on1。PDP（個人成長計画）の進捗を必ず報告する
  • 四半期OKRルール：四半期ごとに3つの目標（業務2＋ヒューマン1）を設定し、上長と合意する
  • 処遇連動ルール：半期評価でB以上を維持できなければ、役割再定義または雇用形態見直しの対象になる
厳守事項 日次入力を週3日以上飛ばした場合は、店長から警告。月単位で改善が見られない場合は評価Cの対象。
振り返りはこの仕組みの心臓部。

OPERATION

具体的な運用方法

サイクル誰が何をする
日次全正社員app.htmlに今日の振り返り＋明日のアクションを1行入力
週次各ポジション担当KPIの数字確認・改善1件提案・店長と簡易共有
月次各ポジション月間レポート（KPI達成度＋改善計画）を店長に提出（月末日）

月次店長×各員1on1（30分）：PDP進捗・四半期OKR進捗を確認
四半期全正社員OKR設定＋360°フィードバック
半期店長×OWNER評価面談（60分）→ 処遇確定（昇給・インセンティブ・改善計画）

05 / 05
NOTES

運用上の注意事項

NOTE 1
処遇は時間でなく成果に連動する
残業時間の長さは評価対象外。むしろ65%ルールを破る働き方は赤信号。「成果を残しつつ時間を守る」が正社員の腕の見せ所。
NOTE 2
エスカレ件数も評価対象
店長への相談・判断依頼が月5件超は自己解決能力の不足とみなす。深刻案件のみエスカレ。
NOTE 3
PDPは半期で更新
スキル目標が達成済みの場合、次のレベルに引き上げる。停滞は「成長していない」のサイン。
NOTE 4
後継育成は採用前提
「自分の代わりがいない」状態は組織リスク。半期で1名以上、後継候補を指名・育成する。
NOTE 5
役割は固定でない
silver A→副店長／silver B→2号店副店長／bronze→silver昇格 など、達成度次第で役割変更あり。
NOTE 6
困った時のSOS
領域責任の重圧で潰れそうになる前に、店長またはOWNERへ早期相談。1人で抱えて辞めるのが最悪のシナリオ。
